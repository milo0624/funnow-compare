第一次使用要貼上 GitHub 權杖（只存在這台裝置的瀏覽器裡）。 產生權杖： Repository access 選 Only select repositories → funnow-compare；Permissions → Repository permissions → Actions 選 Read and write。
目前是範例資料（10 家店）。到 GitHub 的 Actions 頁面執行一次「更新 FunNow 價格」，就會換成完整資料。
FunNow 價：不指定日期時是該方案的起價；選了日期就是那一天最便宜的時段價，同一天不同時段有價差時會顯示「～最高價」。
可選的日期是更新當下 FunNow 開放預訂的範圍：休息約 7 天、住宿約 30 天。
定價：FunNow 頁面標示的店家定價（牌價，通常偏高）。標「官網」的是實際查到的官網售價，會優先用來比；官網有分平日假日時，選到週六、週日用假日價，其餘用平日價。
每列右下角的 # 編號是方案編號，填 official.json 時使用。
